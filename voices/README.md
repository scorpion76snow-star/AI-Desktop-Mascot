# User-provided voice models

This folder is intentionally empty in the public repository.

Place your own Piper voice model and config here, for example:

```text
voice_zh_huayan.onnx
voice_zh_huayan.json
voice_en_alba.onnx
voice_en_alba.json
```

Check the license of each voice model before using or redistributing it.
Voice is disabled by default.
